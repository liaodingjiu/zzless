🎁 How to Redeem Codes in Zenless Zone Zero

  1. Open the game and log in to your account on any platform (PC, Mobile, PS5).
  2. Tap the Menu button (phone icon or ESC key on PC) in the top-left corner.
  3. Select More (bottom-right of the menu panel).
  4. Tap Redemption Code — a text field will appear.
  5. Enter the code exactly as shown (codes are case-sensitive — use uppercase as listed).
  6. Tap Confirm — rewards will be sent to your in-game Mail within a few minutes.
  7. Open the Mail system and claim your items before they expire (mail usually lasts 30 days).

💡 Pro tip: You can also redeem codes via the official HoYoverse website at zenless.hoyoverse.com/redemption — log in with your HoYoverse account and enter the code there.

⚠️ Why Do Codes Stop Working?

Redemption codes in ZZZ (and all HoYoverse games) have a limited lifespan. Here's why a code might not work:

  • Expired — Most codes have an expiration date (usually tied to a patch cycle). Once expired, the code cannot be redeemed.
  • Usage limit reached — Some codes have a global or per-account usage cap. If enough players have redeemed it, new attempts will fail.
  • Region lock — Certain codes are restricted to specific servers (Asia, Europe, America, TW/HK/MO). Always check the region before trying.
  • Already redeemed — Each code can only be used once per account. If you've already claimed it, you'll see a "Code already used" error.
  • Case sensitivity — Codes must be entered exactly as shown, including capitalization. "ZZZ2026" is different from "zzz2026".
  • Typo / formatting — Copy and paste the code directly from this page to avoid typos. All codes listed are verified and formatted correctly.

❓ Frequently Asked Questions

Can I use the same code twice?

No. Each redemption code can only be used once per account. Attempting to reuse a code will show an error.

Do codes work on all servers?

Most codes are global, but some are region-specific (Asia, Europe, America, TW/HK/MO). Check the code's region requirement if it fails.

How often are new codes released?

Typically every 6 weeks with each new patch/version. Extra codes may drop during livestreams, holidays, or special events.

What's the difference between Polychrome and Monochrome?

Polychrome is the free earnable currency. Monochrome is the premium purchased currency that converts 1:1 to Polychrome.
