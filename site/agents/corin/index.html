❓ FAQ — Corin Wickes

Is Corin Wickes worth pulling?
Corin Wickes is a solid A-Rank Attack. A-Ranks are easier to max (cheaper materials, more dupe copies), and a maxed A-Rank often outperforms a base S-Rank. Worth building if you need Physical coverage.
What stats should I prioritize?
CRIT Rate / CRIT DMG > ATK% > Element DMG%. Slot 4: CRIT Rate or CRIT DMG. Slot 5: Physical DMG%. Slot 6: ATK%.
Best F2P Attack W-Engine?
The A-Rank Cannon Rotor and Drill Rig - Red Axis are excellent F2P options for Corin Wickes. CRIT Rate substats provide solid synergy without spending Monochrome.
Which Drive Disc set is best?
For Corin Wickes, the Fanged Metal set (Physical) is generally the strongest choice because the Physical DMG bonus directly amplifies her damage. Mix with a 2-Piece Woodpecker Electro or Astral Voice for the 4+2 setup.
